# Google Drive Sync — сборка

Собранный плагин для Obsidian: двусторонняя синхронизация vault с Google Drive.
Здесь лежит только результат сборки — `manifest.json` и `main.js`. Исходники приватные.

## Установка

Через [BRAT](https://github.com/TfTHacker/obsidian42-brat), в том числе на Android:

1. Community plugins → Browse → **BRAT** → Install → Enable
2. Команда **BRAT: Add a beta plugin for testing**
3. Указать `aidarbn/obsidian-gdrive-sync-dist`
4. Включить **Google Drive Sync** в списке плагинов

Обновления — кнопкой «Check for updates» в BRAT.
